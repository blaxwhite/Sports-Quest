# SPORTS QUEST: Kingdom of Champions

A browser-based Year 5 English learning game built around a fantasy sports kingdom.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Select **Start Adventure**, then choose a location on the kingdom map.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Current prototype
- Kingdom map with six mission locations
- Vocabulary, listening-style announcement, reading comprehension, teamwork, planning and final challenge activities
- XP, progress tracking and Champion Emblems
- Responsive layout for laptop and mobile screens

## CASPER visual design
- **Contrast:** dark navy interface with bright gold and cream highlights.
- **Alignment:** consistent placement of headings, instructions, choices and status information.
- **Simplicity:** short instructions and uncluttered screens.
- **Proximity:** related mission details, questions and answer choices are grouped.
- **Emphasis:** mission titles, questions, progress and rewards are visually prominent.
- **Repetition:** consistent buttons, typography, dialogue panels and colour conventions.
