# SPORTS QUEST soundtrack files

Upload your own licensed or original looping MP3 tracks into this folder using these exact filenames:

- `arcade-theme.mp3` plays on `arcade.html` (Arcade Zone).
- `runner-theme.mp3` plays on `arcade/sports-kingdom-runner.html` (Sports Kingdom Runner).

Both tracks loop automatically after a user interacts with the page, subject to browser autoplay rules. Each page has its own music toggle and volume control. Keep file sizes modest for mobile loading, and use music you have permission to publish.
